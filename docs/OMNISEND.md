# Omnisend web integration

Public brand ID: `6ad63163b4aa089441abd81f`. The asynchronous official launcher is inserted once, only after explicit marketing consent. The first-party consent decision is versioned and expires after 180 days. Footer settings permit withdrawal; the consent API is signalled, visible Omnisend cookies are removed, and a reload unloads the SDK. No name or email is automatically identified. Account, checkout, API routes, query strings and fragments are excluded from loading.

In Omnisend, select **Store settings → Connected store → Wait for consent before tracking**. The browser forwards the current marketing choice through `__omnisendCookieConsent.getConsentAPI({wait:true})` on each eligible page load. Local gating prevents any SDK request before permission independently of that dashboard setting. Verify the setting and any published Omnisend forms in the merchant dashboard.

The snippet does not enable the existing server newsletter endpoint or paid-order event sync. Those remain gated by `OMNISEND_API_KEY`, `OMNISEND_ENABLED`, and, for order events, `OMNISEND_ORDER_EVENTS_ENABLED` and explicit customer subscription. Keep API credentials in hosting secrets. Cookie consent and newsletter consent remain separate.
